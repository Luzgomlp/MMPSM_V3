# Force-field files

This directory contains the molecular topology files used in the MMPSM thermodynamic integration calculations.

The molecular parameters are based on the GROMOS 54A7 parameter set.
The topology files correspond to the solutes and solvent molecules included in the present study.

## Files

- aniline.itp
- formamide.itp
- hexane.itp
- AMP.itp
- HPC.itp
- dacpc.itp
- octanol.itp
- hexadecane.itp

`topol_template.top` illustrates the organization of the topology files used for the simulations. It is provided as a template and is not a complete system-specific topology.
