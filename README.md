# Data and Software Availability

This repository contains the molecular structures, force-field parameters,
simulation protocols, and free-energy results supporting the associated
manuscript.

## Repository contents

### Structures
Contains the molecular structures of the solutes and solvent systems used in the simulations.

### Force_Fields
Contains the GROMACS topology and parameter files used for the molecular systems.

### Protocols
Contains the GROMACS MDP files used for system equilibration, DAcPC:water characterization, and thermodynamic integration.

### free_energy
Contains the BAR free-energy results for the simulated systems.

### DAcPC
Contains the structures and hydrogen-bond analysis data used for the characterization of the DAcPC:water systems.

## Software

The molecular dynamics and free-energy calculations were performed using sGROMACS with the GROMOS54A7 force field and SPC water model.
